# 拾星 1.0.1

1.0.0 之后的修正版，主要修「看不全」和「认不出人」这两类问题。

## 修了什么

**连向我**

- 整页可以上下滚了：顶部聊天条、状态行、卡片在同一层，一起移动
- 卡片背面自己也能滚：`介绍 / 你们的共同点 / 关于我` 再长也不会被卡边截断
- 卡片宽度从 0.94 收到 0.86，四段成分百分比改成等分单行，不再折行

**查看全部**

- 从「一排头像」改成整页头像网格（每行 4 个，可以往下滑）
- 点头像弹出这张星的大卡，点空白处关闭

**星友圈**

- 动态作者：互相连上的显示**照片头像 + VRChat 名**；没连上的显示**模糊照片 + 代号**
- 顶部拆成「动态 / 榜单」两个页签，榜单就是地图榜（点一张图可看/改自己的评分）
- 星搭门票入口（读的是网页侧数据）

**贴纸**

- 接口有的返回位图、有的返回 SVG，现在两路都会渲染（SVG 走本地渲染器，去掉做旧遮罩后按路径重画）

**私聊**

- 列表与对话头都是对方照片做头像 + VRChat 名（星名降为副标题）

## 仍然存在的限制

- 星卡照片清晰度由「对方与你是否互相连上」决定，站点规则
- 「我的仓库 / 兑换码 / 账号与设备」暂时收起，见 `docs/TODO.md`
- 早期星搭门票没有默认摆放，列表可能是空的

## 安装

下载 `app-release.apk` 直接覆盖安装，登录状态会保留。
