## A. 「我的 → 网页功能」里被暂时藏起来的入口

代码里由 `WebFeatures.ALL` 控制（`native/app/src/main/java/app/shixing/client/ui/Pages.kt`），
现在是 `false`，所以「我的」页只留 **装扮** 一项。

| 入口 | 走什么 | 现在的状态 | 为什么先藏 |
| --- | --- | --- | --- |
| 我的仓库 | 网页接口 `bag` | 能拿到贴纸包 / 星尘 / 任务三个数字，但贴纸和卡面没有可点的详情 | 只读还没做成可用的界面，点进去像空壳 |
| 兑换码 | 网页接口 `cdk` / `redeem` | 兑换能调通，失败提示只有一句 | 缺「兑换记录」和错误细分，用户不知道码为什么没用 |
| 账号与设备 | 网页接口 `keys` / `key-drop` | 能列设备、能踢 | 缺「这台是哪台」的辨识（只有 Android·Chrome + 时间） |

**要恢复**：把 `WebFeatures.ALL` 改成 `true` 即全部回来；想单独放行就把它拆成三个常量。
