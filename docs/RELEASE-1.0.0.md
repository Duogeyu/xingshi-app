# 拾星 1.0.0

第一个给人用的版本。它只读星遇同频的官方接口（`/api/v1`），不绕过审核、不自动操作。

## 能做什么

**今天**
一张卡一屏，左右滑动换星。卡上是 TA 的照片（没连上是模糊格，互相连上才清晰）、星名、一句话、四维成分和你们的重合度，点卡翻面看介绍与「你们的共同点」。卡下可以「连一条线」「下一颗」。

**连向我**
顶部是和你有对话的人（照片头像 + VRChat 名 + 最后一句），点「查看全部」摊成头像网格，点头像弹大卡、点空白关掉。下面是连向我的星，按「来自哪个星群 / 和你重合多少 / 是否连上」排列。星轨并在这里，用顶部「连向我 / 星轨」切换。

**星友圈**
「动态 / 榜单」两页签。动态里有星搭门票入口、全部/好友/我的筛选、发动态；作者是互相连上的显示照片和 VRChat 名，没连上的显示模糊照片和代号。榜单是地图榜，点一张图可以看/改自己的评分。

**我的**
自己的星卡（含装扮的卡面与卡背、照片、四维）、今日接口用量、私聊列表、我打过的地图、装扮、（可选）评分提醒。去过的地图还没打分时，顶部会提示一次，可以关掉，第二天才会再问。

**后台提醒**
每 15 分钟问一次有没有新的提醒，有就发系统通知。App 在前台时不打扰。

## 权限

第一次连接会在网页上让你确认权限清单：基本资料、提醒、星轨、互相连上、今天的星、连向我、连线、私聊、星友圈、照片、地图评分等。不同意也不会坏，只是对应页面会显示「需要授权」。

## 已知限制

- 星卡照片的清晰度由**对方与你是否互相连上**决定，这是站点规则，不是我们的选择。
- 早期星搭门票没有默认摆放，列表里可能是空的。
- 部分贴纸接口返回 SVG、部分是位图，两边都在渲染，个别工艺（闪粉/镭射）会略淡。
- 「我的仓库 / 兑换码 / 账号与设备」暂时收起，见 `docs/TODO.md`。

## 安装

下载 `app-release.apk` 直接装。签名是开发证书，覆盖安装会自动保留登录状态。

## 检查更新

「我的 → 关于 → 检查更新」。App 每天也会静默查一次 GitHub Releases，有新版本会在关于里出现「去下载」。
